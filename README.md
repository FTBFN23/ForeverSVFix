## 🗂️ What Are SavedVariables Anyway?

In WoW, each addon saves its settings as a file in a special folder. These files store things like:

- Your chosen positions for frames
- Which modules are enabled or disabled
- Custom colors, fonts, and scales
- Saved statistics or loot lists

When the game beta fails to load these files properly, your addons think they're being run for the first time—and reset. ForeverSVFix repairs this loading process automatically.

## 🧪 How It Works (Simple Explanation)

The game beta uses a slightly different path for storing addon data than the main game does. ForeverSVFix detects this mismatch and corrects the file paths in the background. Think of it like a translator that tells the game, "Hey, the addon settings are actually over here, not there." After the fix, everything clicks into place.
